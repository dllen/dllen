## Project overview

This repository is a GitHub profile README (`dllen/dllen`) that is updated by local Python scripts. `README.md` contains HTML comment markers (`<!--START_SECTION:...-->` / `<!--END_SECTION:...-->`) that the scripts replace with generated content.

## Repository structure

- `README.md` — Profile README. Do not manually edit content between `<!--START_SECTION:...-->` and `<!--END_SECTION:...-->` markers; it is overwritten by scripts.
- `src/getTopFollowers.py` — Queries the GitHub GraphQL API and regenerates the top-followers table in `README.md`.
- `src/updateBlogPosts.py` — Parses `atom.xml` and regenerates the latest blog posts list in `README.md`.
- `src/updateAwesomeStars.py` — Fetches starred repositories and regenerates `AWESOME-STARS.md`.
- `src/updateStarFork.py` — Reads `.env` `GH_TOKEN`, fetches star/fork counts, and updates the repository description.
- `src/updateWakapi.py` — Reads `.env` `WAKAPI_*` secrets and regenerates the coding-time block in `README.md`.
- `AWESOME-STARS.md` — Generated by `src/updateAwesomeStars.py`; do not edit manually.

## Build, test, and lint

There is no build system, package manager configuration, linter, or test suite in this repository.

## Running scripts locally

All updates are driven by scripts in `src/`. Install the single dependency once:

```bash
pip install requests
```

### Update top followers

```bash
python src/getTopFollowers.py <github-handle> <token> README.md
```

The token must have access to the GitHub GraphQL API.

### Update blog posts

```bash
curl -L -o atom.xml https://scp.net.cn/blog/atom.xml
python src/updateBlogPosts.py
rm atom.xml
```

### Update starred repositories

```bash
python src/updateAwesomeStars.py
```

### Update repository description (star/fork counts)

```bash
python src/updateStarFork.py
```

The script reads `GH_TOKEN` from `.env`. The token needs the `public_repo` scope to update the repository description.

### Update Wakapi stats

```bash
python src/updateWakapi.py
```

The script reads `WAKAPI_BASE_URL` and `WAKAPI_API_KEY` from `.env`.

## Required environment variables

Scripts read from `.env`:

- `GH_TOKEN` — GitHub token. Used by `getTopFollowers.py`, `updateAwesomeStars.py`, and `updateStarFork.py`. Needs `public_repo` scope for `updateStarFork.py`.
- `WAKAPI_BASE_URL` and `WAKAPI_API_KEY` — Used by `updateWakapi.py` to fetch coding stats.

## Local secrets

`.env` is gitignored and stores the tokens above for local script runs. Verify it is never committed.

## Testing script changes

Run the relevant script and inspect the generated markers in `README.md` or the output file.
